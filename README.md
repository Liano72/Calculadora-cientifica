# Calculadora cientifica

Meu primeiro projeto utilizando React e JavaScript: uma calculadora científica responsiva, desenvolvida para funcionar tanto através dos botões da interface quanto pelo teclado. O projeto foi desenvolvido com o objetivo de praticar e aprimorar meus conhecimentos em React, JavaScript e CSS.

# 🛠️ Ferramentas utilizadas

   * React
   * CSS
   * JavaScript
